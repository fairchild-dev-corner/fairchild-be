Fairchild Egress Architecture

DigitalOcean's Trusted Sources firewall drops connections from IPs it doesn't recognize — silently, which is why the staging binary sat retrying for five minutes before failing with a plain connection timeout. Railway's egress IP is dynamic, so there's nothing stable to add to that allowlist.

Moving to Cloud Run fixes that, but not for free: GCP has no single "static IP" toggle. The guarantee has to be assembled from four separate billed components sitting between Cloud Run and the internet. Below is the path a request actually takes, and what that assembly costs next to Railway's version of the same guarantee.

Recommendation

For a low-traffic staging service, Cloud Run, Secret Manager, and Artifact Registry all stay within their free tiers on their own — the entire added cost above is the static-egress plumbing, not the app. Weigh ≈$50/mo of standing GCP infrastructure against either re-enabling Railway's static IP toggle, or temporarily opening DigitalOcean's Trusted Sources to 0.0.0.0/0 and leaning on TLS + credentials as the actual gate — cheaper, but worth revisiting before this becomes the production path.
